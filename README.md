## 站点特性

- 左侧章节树 + 逐节「已掌握」勾选（进度存在浏览器本地）
- 每页右上目录、顶部阅读进度条
- 全站搜索（`Ctrl/⌘ + K`）
- 公式用 KaTeX 在构建时预渲染，**不依赖任何 CDN**；离线双击也能看
- 宽屏双栏 / 移动端单栏自适应；表格横向滚动
- 每节分层：物理直觉 → 标准结论 → 深入推导（可折叠）→ 考点 → 真题 → 自测
