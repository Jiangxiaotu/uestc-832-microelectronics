2.5 正向及反向电压下 PN 结中的载流子运动情况

考纲第 5 条。外加偏压如何改变势垒高度与耗尽区，以及正向电流、反向电流各由哪些成分构成、载流子往哪个方向跑。

考纲 2-5）

一句话抓住

外加电压只改变势垒高度与耗尽区宽窄，不改变电场曲线的斜率。

正向电流的电荷来源是多子（所以很大）；反向电流的电荷来源是少子（所以很小）——这就是单向导电性的全部物理。

1. 外加电压对势垒与耗尽区的作用#

外加电压 V 全部降落在耗尽区上时，只需把 §2.4 所有公式中的 Vbi​ 换成 Vbi​−V（注意外加电压的参考极性与 Vbi​ 相反）：

势垒高度: qVbi​ ⟶ q(Vbi​−V)
偏置 势垒高度 耗尽区宽度 xd​ 最大电场 Emax​ 电场曲线面积
正偏 V>0 降低 变窄 变小 Vbi​−V，变小
平衡 V=0 qVbi​ xd0​ Emax0​ Vbi​
反偏 V<0 升高 变宽 变大 Vbi​−V，变大
xd​(V)=xd​(0)Vbi​Vbi​−V​​,Emax​(V)=Emax​(0)Vbi​Vbi​−V​​

图中的量

  • V —— 外加电压（正偏取正、反偏取负）
  • Vbi​ —— 内建电势（平衡时势垒高度为 qVbi​）
  • q(Vbi​−V) —— 加偏压后的势垒高度（正偏降低、反偏升高）
  • xd​ —— 耗尽区宽度（与 Vbi​−V​ 成正比）
  • Emax​ —— 最大电场（与 Vbi​−V​ 成正比）

2. 正向偏压下载流子的运动#

正向电压使势垒降低（由 qVbi​ 降为 q(Vbi​−V)），势垒不再能阻止 N 区电子向 P 区扩散、P 区空穴向 N 区扩散，于是形成正向电流。

为什么正向电流很大

因为正向电流的电荷来源是多子——多子浓度比少子高几个数量级（§2.2），能越过势垒的多子数量极大。

正向电流密度由三部分组成：

J=Jdp​+Jdn​+Jr​
成分 电荷来源 运动方向
Jdp​ 空穴扩散电流密度 P 区多子空穴越过结面进入 N 区，成为 N 区少子 P 区 → N 区
Jdn​ 电子扩散电流密度 N 区多子电子越过结面进入 P 区，成为 P 区少子 N 区 → P 区
Jr​ 势垒区复合电流密度 注入到耗尽区内的电子与空穴在此复合 耗尽区内

进入中性区后的行为： 注入的非平衡少子一边扩散一边复合，浓度按指数式衰减（厚区情形，见 §2.7）。

3. 反向偏压下载流子的运动#

反向电压使势垒升高，多子更难扩散过去；但少子面临的势阱更深，更容易被反向电场拉入对方区域，形成反向电流。

为什么反向电流很小

因为反向电流的电荷来源是少子，而少子浓度比多子低好几个数量级。

反向电流密度也由三部分组成：

J=Jdp​+Jdn​+Jg​
成分 电荷来源 运动方向
Jdp​ 空穴扩散电流密度 N 区体内的少子空穴扩散到耗尽区边界，被强电场拉到 P 区 N 区 → P 区
Jdn​ 电子扩散电流密度 P 区体内的少子电子扩散到耗尽区边界，被强电场拉到 N 区 P 区 → N 区
Jg​ 势垒区产生电流密度 耗尽区内热激发产生电子空穴对，被电场分别拉向两侧 耗尽区内

反向电流的关键结论

反向电流的主要成分来自低掺杂一侧区中的少子。 原因：反向饱和电流 J0​∝N1​（见 §2.9），低掺杂一侧的分母最小、贡献最大。

4. 一个容易忽略的细节：各截面上的电流比例不同#

在平行于结面的任何截面，电子电流与空穴电流不相等，但流过截面的总电流相等。不同截面上电子电流与空穴电流的比例不同：

  • 从 P 区深处到结面，空穴电流逐渐减小、电子电流逐渐增大（因为少子在扩散途中复合）；
  • 穿过耗尽区时，忽略复合电流，可认为电子电流和空穴电流各自保持不变：
Jn​(−xp​)=Jn​(xn​),Jp​(xp​)=Jp​(−xn​)

因此总电流为

J=Jp​(xn​)+Jn​(xn​)=Jp​(−xp​)+Jn​(−xp​)=J扩p​(xn​)+J扩n​(−xp​)

这条"分割再相加"的思路，正是 §2.8 推导 I–V 方程的基础。

题会怎么出

  1. 填空/简答："外加正向电压后，势垒高度由 ___ 变为 ___；耗尽区宽度变 ___，最大电场变 ___。"
  2. 成分分析题：写出正向电流与反向电流各自的三种成分，并说明电荷来源（多子/少子）与运动方向。
  3. 图解题：给出正向/反向偏压下的能带图或电场分布图，要求判断偏置方向并说明理由。
  4. 反向电流来源："反向电流主要由 __ 区的少子产生"——填低掺杂。
  5. 载流子方向判断：注入 N 区的非平衡载流子是什么？（空穴）注入 P 区的是什么？（电子）

5. 易错点#

  • 把"正向电流大"归因于"电场大"：正相反，正偏时电场变小；正向电流大是因为电荷来源是多子。
  • 忘记势垒区复合/产生电流：正向小偏压段与反向低温段的电流完全由它主导（§2.8）。
  • 混淆"扩散电流方向"与"载流子运动方向"：空穴向右扩散、电子向左扩散，但两者形成的扩散电流方向相同。
  • 误以为反偏时"少子更容易扩散过去"：反偏时少子是被电场拉过去（漂移），不是扩散。

6. 自测#

自测

  1. 写出正偏、反偏时势垒高度与耗尽区宽度的变化方向。
  2. 正向电流有哪三种成分？各自对应什么载流子的什么运动？
  3. 为什么反向电流很小？为什么它主要来自低掺杂一侧？
  4. 某 PN 结平衡时势垒高度 0.6 eV，外加反向电压 2.4 V 后势垒高度变为多少？

解析要点

  1. 正偏：势垒降低、xd​ 变窄、Emax​ 变小；反偏相反。
  2. Jdp​（多子空穴扩散）+ Jdn​（多子电子扩散）+ Jr​（耗尽区内复合）。
  3. 电荷来源是少子，浓度比多子低几个数量级；J0​∝1/N，低掺杂侧分母最小。
  4. q(Vbi​−V)：0.6+2.4=3.0 eV。
