832 微电子器件 · 考点精讲#

把课件、考纲、教材与历年真题整理成一套「可分层阅读、可定位考点、可跟进度」的复习文档。目录严格按《微电子器件考试大纲》的条目组织——第 2 章 PN 结已按考纲的 15 条全部展开，后续章节按同一工作流滚动更新。

电子科技大学 · 集成电路科学与工程学院 832 微电子器件 参考教材：陈星弼《微电子器件》第四版 部分内容参考《半导体物理学》

怎么用这个网站#

  1. 先看「一句话抓住」——每节开头的绿色框是这一节的物理内核，先用 1 分钟建立直觉；
  2. 再读正文——蓝色框（题会怎么出）与橙色框（真题/例题）直接对着考试；虚线框（展开）是需要深挖的推导；
  3. 做完自测——灰框是对应小节的自测题，答案要点就在下面；
  4. 勾选进度——左侧每一节前面的小方框可以标记「已掌握」，进度会存在浏览器本地，随时接着看；
  5. 随时检索——按 Ctrl+K（Mac 用 ⌘K）可以全站搜索考点，例如输入「雪崩」「耗尽区宽度」「Webster」。

复习温馨提示（2024 复习大纲原文，请务必照做）

  • 课件和教材必看；
  • 符号要写对，比如 EF​、qVbi​ 等等；
  • 能带图要标注清楚，注意细节（耗尽区宽度宽窄、费米能级之差等）；
  • 坐标图要标注横坐标、纵坐标、参变量；
  • 作业、课堂例题要搞明白，尤其是带星号的题目；
  • 基本常数、核心公式、重要物理图像、蓝色背景的公式要牢记；
  • 各个基本概念、器件工作原理要熟练掌握；
  • 该理解的自己推导一遍，理清思路；
  • 复习大纲只是重点提示，需要对着课件 PPT 理解透，考试内容覆盖全部授课内容；
  • 审题要仔细，比如求少子还是过剩少子，多子还是少子等等。

本站内容是如何生成的#

本站不是手抄笔记，而是用一套可重复运行的流水线做出来的：

原始资料（PPT / PDF 课件 / 考纲 / 习题 / 真题）
        │  ① 抽取：脚本把 PDF、PPTX、DOCX 抽成带页码标记的 Markdown
        ▼
结构化中间稿（raw/）
        │  ② 对齐：与考纲条目、老师的分章节 Checklist、历年真题逐条对齐
        ▼
分层讲稿（content/，Markdown + LaTeX + SVG 图）
        │  ③ 构建：Node 脚本渲染公式（KaTeX）与图形，生成静态站点
        ▼
可分享的静态网站（site/ → GitHub Pages）

每次更新资料，只要重跑 ①②③ 三步，网站内容与链接都不变。

关于内容准确性

本站结论整理自课件、复习大纲、老师的分章节重点与历年真题，公式已按教材符号统一。 个别真题的数值（尤其是尚未公开标准答案的考题）标注为"参考解"，请以老师答案为准。 任何与本课程课件/教材冲突之处，一律以课件与教材为准。
