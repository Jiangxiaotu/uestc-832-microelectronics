工具 · 自查

怎么用

每条都能合上所有资料、口头讲清楚，才勾上。 真正掌握的标准不是"看着眼熟"，而是能独立写出公式 + 画出图 + 说出物理原因。

2.1 平衡状态#

  • 能说出耗尽近似与中性近似的准确定义，并说明为什么可以用它们
  • 能写出空间电荷区（N 区电离施主、P 区电离受主）与中性区的电荷组成，并算出平衡多子、平衡少子浓度
  • 能完整复述空间电荷区形成的四步：电中性 → 扩散 → 电中性被打破 → 内建电场（方向由净正电荷区指向净负电荷区）
  • 能说出四种"变形情形"：普通突变 PN 结、同型突变结、大注入、缓变基区，并指出各自的关键差异
  • 能写出三个区（P 型耗尽区、本征 I 层、N 型耗尽区）的泊松方程形式，并说明"电场分布曲线的斜率"这一图像
  • 能由 ND​xn​=NA​xp​、Emax​ 与 xd​ 的关系、Vbi​=21​xd​Emax​ 快速推出 xd​ 与 Emax​
  • 会算约化浓度 N0​，并说明单边突变结时它等于什么
  • 能说出 PN 结两区耗尽区的分压规律 Vbi​(N)Vbi​(P)​=xn​xp​​=NA​ND​​
  • 能画出平衡 PN 结能带图，标出 EC​、EV​、Ei​、EF​、qVbi​ 与耗尽区宽窄
  • 能写出线性缓变结的 E(x)、Emax​、xd​、Vbi​，并说出与突变结的幂次差别
  • 能做"某区掺杂升高后，Emax​、xd​、xn​、xp​ 怎么变"的趋势判断

2.2 直流 I–V 方程#

  • 能写出小注入结定律并解释它的适用条件（正向限小注入）
  • 能区分少子浓度与过剩少子浓度，并在题目里正确选择
  • 能画出正向/反向偏压下的少子分布图（厚区指数、薄区线性）
  • 能说出"电场分布曲线包围的面积为 Vbi​−V"，并会用相似三角形说明 Emax​ 与 xd​ 同步变化
  • 能说出平衡势垒高度 qVbi​、加偏压后 q(Vbi​−V)
  • 能列出正向电流的三种成分与反向电流的三种成分，并说明各自对应的载流子运动方向
  • 能说出正向电流从小到大依次以什么为主（复合 → 扩散 → 大注入），并对应 lnI∼V 的斜率变化（q/2kT→q/kT→q/2kT）
  • 能说明为什么反向电流主要来自低掺杂区的少子
  • 能说出提高掺杂浓度对 Emax​、xd​、Vbi​、CT​、I0​ 的影响
  • 能判断厚区/薄区，并写出两种情况下的少子浓度分布与电流密度公式
  • 能处理"一厚一薄"的组合（两种少子扩散电流相加）
  • 能写出正向导通电压的定义、计算与温度关系（负温度系数）
  • 能比较 Jr​ 与 Jd​（正偏），以及 Jg​ 与 Jd​（反向，与温度的关系）

2.3 大注入#

  • 能写出小注入/大注入判据，并判断哪一侧发生大注入
  • 知道"最多只有一个区发生大注入，只有低掺杂区可能发生"
  • 能说清大注入自建电场的产生原因、方向，以及对少子/多子分别是加速还是减速
  • 能解释 Webster 效应（D→2D，L→2​L）
  • 能写出大注入结定律与对应的电流表达式（qV/2kT）
  • 会算 N 区厚区 / 薄区的转折电压
  • 能快速写出"厚薄区 × 大小注入"四种组合下的少子分布与电流公式

2.4 击穿#

  • 知道碰撞电离率的大小关系（Si vs Ge）与禁带宽度的关系
  • 能说出什么情况下容易发生齐纳击穿、什么情况下容易发生雪崩击穿
  • 能写出 PN 结雪崩击穿条件
  • 能说清掺杂浓度、低掺杂区厚度、结深对 VB​ 的影响
  • 能说出三种击穿机理的温度系数，以及如何做出温度系数为零的稳压管
  • 能推出突变结与线性缓变结的 VB​ 表达式，并说明"可忽略 Vbi​"的条件
  • 会用相似三角形做击穿电压计算（含梯形情形）
  • 知道**穿通（punch-through）**发生的条件与判据
  • 能背出提高击穿电压的四条措施
  • 能说出热击穿的物理过程、条件与不可逆性

2.5 / 2.6 电容与交流小信号#

  • 能说出势垒电容与扩散电容各自的电荷来源
  • 能写出突变结与线性缓变结的 CT​–V 幂函数关系（−1/2 / −1/3）
  • 能写出 CD​ 与 IF​、τ 的关系，并说明它是线性（对 IF​）与指数（对 V）的
  • 能完整说出两种电容的六条对照
  • 能说出势垒电容与真实低掺杂区厚度的关系（厚度不足时变成梯形）
  • 会做 C–V 测掺杂的测量方法题

2.7 开关特性#

  • 能回答"为什么 PN 结二极管存在反向恢复时间"
  • 能说出减少 tr​ 的电路 / 器件 / 结构三类措施
  • 能写出电荷控制方程并指出存储电荷减少的两个途径
  • 会算 反向恢复时间 tr​，也会算"给定开关频率下的最大允许 tr​"
  • 能写出厚 N 区与薄 N 区的存储电荷量
  • 能列出 PN 结的五种用途

跨章节的"单边突变结"总结题#

必须能一口气说出：单边突变结中哪些物理量取决于低掺杂侧的掺杂浓度？

  1. 空间电荷区（耗尽区）宽度 xd​；
  2. 最大电场强度 Emax​；
  3. 约化掺杂浓度 N0​；
  4. 正向扩散电流（密度）；
  5. 反向饱和电流（密度）；
  6. 正向导通电压 VF​；
  7. 反向击穿电压 VB​；
  8. 势垒电容 CT​；
  9. 扩散电容 CD​；
  10. 中性区存储的非平衡少子数目（电荷量 Q）；
  11. 反向恢复时间 tr​（开关速度）；
  12. 是否会发生大注入；
  13. 热击穿的容易程度。

记法： 这 13 项全部由 xn​ND​=xp​NA​ 这条电中性条件派生——低掺杂侧"提供电荷的能力弱"，所以所有"宽度/浓度敏感"的量都由它决定。
